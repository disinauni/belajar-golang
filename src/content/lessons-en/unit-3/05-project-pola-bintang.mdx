# Project: Star Patterns

You've mastered every form of looping in Go: `for` in its three variations, `range`, `break`/`continue`/labels, and nested loops. Time to combine it all into one real program — a **star pattern generator** that can print several kinds of patterns at once.

## Program Specification

Our program needs to:

1. Ask the user for a **pattern size** (number of rows)
2. Ask the user to choose a **pattern type**: right triangle, inverted triangle, or pyramid
3. Print the chosen pattern at the given size

Expected interaction example (size 4, triangle choice):
```
=== STAR PATTERN GENERATOR ===

Enter pattern size: 4
Choose pattern (1=Triangle, 2=Inverted Triangle, 3=Pyramid): 1

*
**
***
****
```

## Stage 1: Planning

**What data do we need to store?**
- Pattern size (number of rows — `int`)
- Pattern type choice (`int` or `string`)

**Program flow:**
1. Display the title
2. Prompt for the size
3. Prompt for the pattern choice
4. Print the chosen pattern with a nested loop
5. If the choice is invalid, display an error message

**Edge cases to think about:**
- What if the entered size is 0 or negative?
- What if the pattern choice isn't 1, 2, or 3?

## Stage 2: Pseudocode

```
PROGRAM StarPattern:
    DISPLAY title "STAR PATTERN GENERATOR"

    ASK for size (int)
    IF size <= 0:
        DISPLAY "Size must be greater than 0!"
        STOP

    ASK for choice (int)

    IF choice is 1 (Triangle):
        FOR row FROM 1 TO size:
            PRINT "row" number of stars
    IF choice is 2 (Inverted Triangle):
        FOR row FROM size DOWN TO 1:
            PRINT "row" number of stars
    IF choice is 3 (Pyramid):
        FOR row FROM 1 TO size:
            PRINT spaces then stars, centered
    OTHERWISE:
        DISPLAY "Invalid choice!"
```

## Stage 3: Implementation

### Version 1: Basic Skeleton

Start with a skeleton that reads input, without printing any pattern yet:

```go
package main

import (
    "bufio"
    "fmt"
    "os"
    "strconv"
)

    fmt.Println("=== STAR PATTERN GENERATOR ===")

        return

    fmt.Print("Choose pattern (1=Triangle, 2=Inverted Triangle, 3=Pyramid): ")
    scanner.Scan()
    choice, _ := strconv.Atoi(scanner.Text())

    fmt.Println()
    fmt.Println("Size:", size, "Choice:", choice)
    // TODO: print the chosen pattern
}
```

Try running it — the program can already accept input and validate the size, even though it doesn't print any pattern yet.

### Version 2: Add the Pattern Logic

Now let's add the printing logic for all three pattern types, using `switch`:

```go
package main

import (
    "bufio"
    "fmt"
    "os"
    "strconv"
    "strings"
)

func main() {
    scanner := bufio.NewScanner(os.Stdin)

    fmt.Println("=== STAR PATTERN GENERATOR ===")
    fmt.Println()

    fmt.Print("Enter pattern size: ")
    scanner.Scan()
    size, _ := strconv.Atoi(scanner.Text())

    if size <= 0 {
        fmt.Println("Size must be greater than 0!")
        return
    }

    fmt.Print("Choose pattern (1=Triangle, 2=Inverted Triangle, 3=Pyramid): ")
    scanner.Scan()
    choice, _ := strconv.Atoi(scanner.Text())

    fmt.Println()

    switch choice {
    case 1:
        for row := 1; row <= size; row++ {
            fmt.Println(strings.Repeat("*", row))
        }
    case 2:
        for row := size; row >= 1; row-- {
            fmt.Println(strings.Repeat("*", row))
        }
    case 3:
        for row := 1; row <= size; row++ {
            spaces := strings.Repeat(" ", size-row)
            stars := strings.Repeat("*", 2*row-1)
            fmt.Println(spaces + stars)
        }
    default:
        fmt.Println("Invalid choice! Use 1, 2, or 3.")
    }
}
```

This is the complete version of our pattern generator! Let's understand the important parts.

## Understanding the Code

### strings.Repeat Replaces a Manual Nested Loop

```go
fmt.Println(strings.Repeat("*", row))
```

Instead of writing a manual nested loop to print `row` stars one at a time, we use `strings.Repeat("*", row)`, which returns a string containing `"*"` repeated `row` times. It's still conceptually "nested" (an outer loop for the rows, with the "inner loop" replaced by `strings.Repeat`), but the code is more concise and easier to read.

### Pyramid: Combining Spaces + Stars

```go
spaces := strings.Repeat(" ", size-row)
stars := strings.Repeat("*", 2*row-1)
fmt.Println(spaces + stars)
```

A pyramid needs two parts per row: spaces on the left (to center the stars) and stars in the middle. For `row` 1 of `size=4`: spaces `4-1=3`, stars `2*1-1=1`. For `row` 4: spaces `4-4=0`, stars `2*4-1=7`. Try calculating it by hand on paper if you're not sure about the pattern yet!

### Inverted Triangle: A Backward Loop

```go
for row := size; row >= 1; row-- {
```

Notice this `for` starts at `size` and **decreases** (`row--`) down to `1`. This is the reverse of a regular ascending loop — Go doesn't care which direction you go, `for` is flexible enough for both.

## Complete Solution Code (Final Version)

```go
package main

import (
    "bufio"
    "fmt"
    "os"
    "strconv"
    "strings"
)

func main() {
    scanner := bufio.NewScanner(os.Stdin)

    // === Header ===
    fmt.Println("=============================")
    fmt.Println("  GO STAR PATTERN GENERATOR  ")
    fmt.Println("=============================")
    fmt.Println()

    // === Input ===
    fmt.Print("Enter pattern size: ")
    scanner.Scan()
    size, err := strconv.Atoi(scanner.Text())
    if err != nil || size <= 0 {
        fmt.Println("\n[ERROR] Size must be a number greater than 0!")
        return
    }

    fmt.Print("Choose pattern (1=Triangle, 2=Inverted Triangle, 3=Pyramid): ")
    scanner.Scan()
    choice, _ := strconv.Atoi(scanner.Text())

    fmt.Println()

    // === Print Pattern ===
    switch choice {
    case 1:
        for row := 1; row <= size; row++ {
            fmt.Println(strings.Repeat("*", row))
        }
    case 2:
        for row := size; row >= 1; row-- {
            fmt.Println(strings.Repeat("*", row))
        }
    case 3:
        for row := 1; row <= size; row++ {
            spaces := strings.Repeat(" ", size-row)
            stars := strings.Repeat("*", 2*row-1)
            fmt.Println(spaces + stars)
        }
    default:
        fmt.Println("[ERROR] Invalid choice! Use 1, 2, or 3.")
        return
    }

    fmt.Println("\nThanks for using the pattern generator!")
}
```
