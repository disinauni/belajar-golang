# For Loop

If you've seen code from other languages, you know there's `for`, `while`, and `do-while`. Go simplifies all of that into **just one keyword: `for`**. Don't mistake this for Go "lacking features" — it's actually a deliberate design decision that makes Go simpler to learn.

## Form 1: For with Three Clauses

This is the form most similar to other languages — if you've used `for (int i=0; i<n; i++)` in C++/Java, this is the pattern:

```go
package main

import "fmt"

func main() {
    for i := 0; i < 5; i++ {
        fmt.Println("Loop number", i)
    }
}
```

Output:
```
Loop number 0
Loop number 1
Loop number 2
Loop number 3
Loop number 4
```

## Breaking Down the Three Clauses

**`i := 0`** — the **init** clause, run once at the start, before the loop begins.

**`i < 5`** — the **condition** clause, checked before every iteration. The loop keeps running as long as this is `true`.

**`i++`** — the **post** clause, run after every iteration finishes.

Just like `if`, notice there are **no parentheses** around the three clauses — they're only separated by semicolons, and the curly braces `{}` are still mandatory.

## Form 2: For as a While Loop

If you only need a condition without an explicit init/post, just write the condition on its own:

```go
package main

import "fmt"

func main() {
    n := 1
    for n <= 16 {
        fmt.Println(n)
        n *= 2
    }
}
```

Output:
```
1
2
4
8
16
```

This is equivalent to `while (n <= 16)` in other languages — Go doesn't need a separate keyword, just `for` with a single condition.

## Form 3: Infinite Loop

Without any clauses at all, `for` becomes an infinite loop — useful when you want to control the exit yourself with `break` somewhere in the block:

```go
package main

import "fmt"

func main() {
    count := 0
    for {
        count++
        fmt.Println("Iteration:", count)
        if count >= 3 {
            break
        }
    }
}
```

Output:
```
Iteration: 1
Iteration: 2
Iteration: 3
```

**`for {`** — with no condition at all, this means "always true," so the loop will run forever unless there's a `break` (or `return`) inside it.

:::note
This is a pattern often used for servers that need to keep "listening" for requests, or games that keep running until the player quits. You'll see `for { ... }` a lot in real-world Go code.
:::

:::tip
Go doesn't have `do-while` (a loop whose body runs at least once before the condition is checked). If you need that behavior, use this pattern: run the loop body once outside, then wrap the rest with `for condition { ... }`, or use an infinite loop with a condition check + `break` at the end of the loop body.
:::

## Common Mistakes

1. **Adding parentheses around the clauses:**
   ```go
   for (i := 0; i < 5; i++) {  // ERROR: syntax error
       fmt.Println(i)
   }
   ```
   Just like `if`, parentheses around the `for` clauses are **not valid** in Go.

2. **Forgetting `break` in an infinite loop, so the program never stops:**
   ```go
   for {
       fmt.Println("This will print forever...")
       // forgot break!
   }
   ```
   Always make sure there's a way out (`break` or `return`) in an infinite loop, or the program will hang (or time out, in the playground).

3. **Forgetting to update the variable in a while-style loop, causing an accidental infinite loop:**
   ```go
   n := 1
   for n <= 5 {
       fmt.Println(n)
       // forgot n++  → loops forever!
   }
   ```

## Summary

| Form | Example | Equivalent to |
|---|---|---|
| Three clauses | `for i := 0; i < n; i++ { ... }` | classic for |
| Condition only | `for condition { ... }` | while |
| No clauses | `for { ... }` | while(true), needs a break |
