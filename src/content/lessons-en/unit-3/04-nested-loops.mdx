# Nested Loops

You already got a glimpse of nested loops in the Labels lesson. Now let's master this pattern formally — it's the essential foundation for this unit's project: building a star pattern.

## A Loop Inside a Loop

```go
package main

import "fmt"

func main() {
    for row := 1; row <= 3; row++ {
        for col := 1; col <= 3; col++ {
            fmt.Printf("(%d,%d) ", row, col)
        }
        fmt.Println()
    }
}
```

Output:
```
(1,1) (1,2) (1,3) 
(2,1) (2,2) (2,3) 
(3,1) (3,2) (3,3) 
```

## Breaking Down the Nested Loop

**The outer loop (`row`)** runs 3 times. **For every single iteration of the outer loop**, the inner loop (`col`) runs **fully** from start to finish (3 times as well) — so overall the inner loop executes `3 × 3 = 9` times.

**`fmt.Println()`** sits outside the inner loop (but still inside the outer loop) — it's called once every time a `row` finishes, to move to a new line in the output.

Think of it like a clock: for every one turn of the hour hand (outer loop), the second hand (inner loop) has already gone around 60 full times.

:::tip
A simple rule for calculating a nested loop's total iterations: multiply the iteration counts of each level. Outer loop 3x, inner loop 3x → total `3 × 3 = 9` executions of the innermost part. If you have 3 nested levels each running 10x, the total is `10 × 10 × 10 = 1000`!
:::

## Building a Simple Pattern

```go
package main

import "fmt"

func main() {
    for row := 1; row <= 5; row++ {
        for col := 1; col <= row; col++ {
            fmt.Print("*")
        }
        fmt.Println()
    }
}
```

Output:
```
*
**
***
****
*****
```

Notice `col <= row` — not a fixed number! The number of stars per row **changes** based on the current value of `row`. This is a very common pattern for building triangles, and it's the foundation for the star pattern project in the next lesson.

:::note
The nested loop trick for patterns: the outer loop usually controls **how many rows**, and the inner loop controls **what gets printed on that one row**. The inner loop's condition often depends on the outer loop's variable, like the `col <= row` example above.
:::

## Common Mistakes

1. **Swapping the variables, producing a pattern flipped from what you expected:**
   ```go
   for row := 1; row <= 5; row++ {
       for col := 1; col <= 6-row; col++ {  // not <= row
           fmt.Print("*")
       }
       fmt.Println()
   }
   // Produces an inverted triangle, not a regular one
   ```
   Always double-check the inner loop's condition carefully — a swapped `<=` vs `>=`, or the wrong variable, can flip the entire pattern.

2. **Forgetting `fmt.Println()` to move to a new line:**
   ```go
   for row := 1; row <= 3; row++ {
       for col := 1; col <= 3; col++ {
           fmt.Print("*")
       }
       // forgot fmt.Println() here!
   }
   // Output: *********  (everything sticks together on one line)
   ```

## Summary

| Concept | Explanation |
|---|---|
| Nested loop | A loop inside a loop |
| Total iterations | Multiply the iteration counts of each level |
| Outer loop | Usually controls the number of rows |
| Inner loop | Usually controls the content of one row |
| Dynamic condition | The inner loop's condition can depend on the outer loop's variable |
