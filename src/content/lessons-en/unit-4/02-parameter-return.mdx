# Parameters & Return

The `greet()` function from the previous lesson always printed the exact same message — not very flexible. Functions become far more useful when they can **receive data** (parameters) and **return a result** (return value). Let's build a function that actually "works" with the data you give it.

## A Function with Parameters and Return

```go
package main

import "fmt"

func add(a int, b int) int {
    result := a + b
    return result
}

func main() {
    total := add(3, 4)
    fmt.Println(total)
    fmt.Println(add(10, 20))
}
```

Output:
```
7
30
```

## Breaking Down Parameters and Return

**`func add(a int, b int) int`** — let's break it down:
- `a int, b int` — the **parameter** list: variables that receive values from the caller, each with an explicit type. Unlike Python or JavaScript, in Go **every parameter must have a type** — there's no such thing as an "untyped" parameter
- `int` (after the parentheses) — the **return type**: the type of data this function will return

**`return result`** — returns the value `result` to the caller, and **immediately stops** execution of the function at that point. Any code after `return` in the same function will never run.

**`add(3, 4)`** — calls the function with the **arguments** `3` and `4`. These arguments are copied into the parameters `a` and `b` inside the function. The returned value (`7`) can be used right away — stored in a variable (`total := add(3, 4)`) or used directly (`fmt.Println(add(10, 20))`).

Think of a function like a vending machine: you insert money (the argument), the machine processes it (the function body), and you receive an item (the return value) at the end.

### Shorthand for Same-Typed Parameters

When several consecutive parameters share the same type, you can write the type just once at the end:

```go
func add(a, b int) int {
    return a + b
}
```

This is exactly equivalent to `func add(a int, b int) int` — just more concise. The rule: the type only needs to be written after the **last** parameter in a group that shares that type.

:::note
**Parameters are passed by value (copied)** — when you call `add(3, 4)`, the values `3` and `4` are **copied** into the parameters `a` and `b`. Changing `a` inside the function does **not** affect the original variable in the caller. This differs from some other languages that pass objects by reference by default.
:::

:::tip
If a group of parameters has mixed types, you can combine the shorthand and explicit styles: `func buildProfile(name string, age, height int)` — `age` and `height` are both `int` so they only need to be written once, but `name` has a different type so it still needs an explicit type.
:::

## Example: Mixed Parameters

```go
package main

import "fmt"

func introduce(name string, age int) string {
    return name + " is " + fmt.Sprint(age) + " years old"
}

func main() {
    fmt.Println(introduce("Rani", 20))
}
```

Output:
```
Rani is 20 years old
```

Notice `fmt.Sprint(age)` — used to convert the `int` into a `string` so it can be joined with `+`. Go doesn't allow you to join a `string` and an `int` directly with `+` (different types must be converted first — the same type-conversion principle you learned back in Unit 1).

## Common Mistakes

1. **Forgetting to write the return type, but still having a `return` statement:**
   ```go
   func add(a, b int) { // ERROR: no return type declared
       return a + b     // ERROR: too many return values
   }
   ```
   If a function returns a value, the return type **must** be declared after the parameter list.

2. **A function with a return type that forgets `return` on some paths:**
   ```go
   func absolute(n int) int {
       if n < 0 {
           return -n
       }
       // ERROR: missing return at end of function
   }
   ```
   Go **forces** every possible execution path to end with a `return` if the function has a return type — the compiler will reject any path that "escapes" without returning.

3. **Assuming changes to a parameter inside a function affect the original variable:**
   ```go
   func double(n int) {
       n = n * 2
   }

   func main() {
       number := 5
       double(number)
       fmt.Println(number) // still 5, not 10 — because n is just a copy
   }
   ```

## Summary

| Concept | Example |
|---|---|
| Explicit parameters | `func f(a int, b int)` |
| Shorthand parameters (same type) | `func f(a, b int)` |
| Return type | `func f(a, b int) int` |
| Returning a value | `return result` |
| Parameters = copies (by value) | Changing a parameter doesn't affect the original variable |

So far our functions can only return a **single** value. In the next lesson we'll learn one of Go's most distinctive features: **multiple return values** — returning more than one value at once from a single function.
