# Variadic Functions

What if you wanted a function that could sum 2 numbers, or 5 numbers, or even 0 numbers — without writing a different version for each argument count? Go has an answer: **variadic functions**, functions that can accept any number of arguments for a single parameter.

## A Simple Variadic Function

```go
package main

import "fmt"

func sum(numbers ...int) int {
    total := 0
    for _, n := range numbers {
        total += n
    }
    return total
}

func main() {
    fmt.Println(sum(1, 2, 3))
    fmt.Println(sum(10, 20, 30, 40))
    fmt.Println(sum())
}
```

Output:
```
6
100
0
```

## Breaking Down Variadic Syntax

**`numbers ...int`** — the three dots (`...`) before the type mark this parameter as **variadic**: it can accept zero, one, or any number of `int` arguments. Inside the function, `numbers` is treated as `[]int` (a slice of int) — you can use `range` on it just like any other slice. (We'll cover slices in detail in Unit 5 — for now, just think of `[]int` as "a sequential collection of int numbers.")

**`for _, n := range numbers`** — iterates over every element in `numbers`, accumulating it into `total`.

**`sum()`** with no arguments at all — still valid! `numbers` inside the function becomes an empty slice, the `range` loop never runs, and the function returns `0` (the initial value of `total`).

Think of a variadic parameter like an elastic shopping basket — you can put as many items into it as you like, even leave it completely empty, and it's still "one basket" that you can process all at once.

:::note
A variadic parameter **must** be the **last** parameter in the parameter list, and a function can only have **one** variadic parameter. `func f(a int, b ...string)` is valid, but `func f(a ...int, b string)` or `func f(a ...int, b ...string)` is not allowed by Go.
:::

## Calling with a Slice: the Spread Operator

If the data you want to send is already a slice, you can "unpack" it into individual arguments with the spread operator `...` after the variable name:

```go
package main

import "fmt"

func sum(numbers ...int) int {
    total := 0
    for _, n := range numbers {
        total += n
    }
    return total
}

func main() {
    numberList := []int{5, 10, 15}
    fmt.Println(sum(numberList...))
}
```

Output:
```
30
```

**`numberList...`** — three dots **after** the slice variable's name means "spread the contents of this slice out as separate arguments," not "send this slice as a single argument." Without `...` here, Go would refuse to compile because the types don't match (`[]int` is not `int`).

:::tip
Three dots (`...`) play two different roles depending on where they appear: in a **parameter declaration** (`func f(x ...int)`), it means "collect the arguments into a slice." In a **function call** (`f(slice...)`), it means "spread the slice out into individual arguments." Opposite directions, same symbol!
:::

## A Real Example: fmt.Println Is Variadic Too!

You've actually been using a variadic function since Unit 1 without realizing it:

```go
fmt.Println("a", "b", "c") // accepts 3 arguments
fmt.Println(1, 2)          // accepts 2 arguments
fmt.Println()              // accepts 0 arguments
```

Its actual signature is roughly `func Println(a ...interface{}) (n int, err error)` — that's why `fmt.Println` can accept any number of arguments of any type.

## Common Mistakes

1. **Sending a slice without the spread operator:**
   ```go
   numberList := []int{1, 2, 3}
   sum(numberList) // ERROR: cannot use numberList (type []int) as type int
   ```
   Without `...`, Go thinks you want to send `numberList` as a single `int` argument — but its type is `[]int`. The fix: `sum(numberList...)`.

2. **Placing the variadic parameter somewhere other than last:**
   ```go
   func print(label string, numbers ...int, note string) { // ERROR
       // ...
   }
   ```
   The variadic parameter must always be the very last parameter.

3. **Assuming a function can have more than one variadic parameter:**
   ```go
   func combine(a ...int, b ...string) { // ERROR: only one variadic allowed
       // ...
   }
   ```

## Summary

| Concept | Example |
|---|---|
| Variadic declaration | `func f(x ...int)` |
| Parameter inside the function | Treated as `[]int` |
| Calling with individual arguments | `f(1, 2, 3)` |
| Calling with a slice (spread) | `f(slice...)` |
| Positional rule | Must be the last parameter, only one allowed |
