# Project: Simple Calculator

Congratulations! You've learned all the fundamental concepts in Unit 1. Now it's time to combine everything into one real project — a **Simple Calculator**.

This is your first project, so we'll walk through every stage slowly: from planning to implementation and testing. This is how professional programmers work — not diving straight into code, but **planning first**.

## Program Specification

Our calculator needs to:

1. Ask the user for a **first number**
2. Ask the user for an **operator** (+, -, *, /)
3. Ask the user for a **second number**
4. Calculate and display the **result**

Expected interaction example:
```
=== SIMPLE CALCULATOR ===

Enter the first number: 15
Enter the operator (+, -, *, /): *
Enter the second number: 4

Result: 15 * 4 = 60
```

## Stage 1: Planning

Before writing a single line of code, let's think it through:

**What data do we need to store?**
- First number (decimal — `float64`)
- Second number (decimal — `float64`)
- Operator (a single symbol — we'll store it as `string`, since input from `scanner.Text()` is always a string)
- The calculation result (decimal — `float64`)

**Program flow:**
1. Display the calculator title
2. Prompt for the first number
3. Prompt for the operator
4. Prompt for the second number
5. Calculate based on the chosen operator
6. Display the result

**Edge cases to think about:**
- What if the user divides by 0?
- What if the user enters an invalid operator?

## Stage 2: Pseudocode

Pseudocode is "fake code" — writing out the program's logic in plain human language before turning it into Go. It helps us think through the logic without getting distracted by syntax.

```
PROGRAM Calculator:
    DISPLAY title "SIMPLE CALCULATOR"

    ASK for number1 (float64)
    ASK for operation (string)
    ASK for number2 (float64)

    IF operation is "+":
        result = number1 + number2
    IF operation is "-":
        result = number1 - number2
    IF operation is "*":
        result = number1 * number2
    IF operation is "/":
        IF number2 is 0:
            DISPLAY "Error: cannot divide by 0!"
        OTHERWISE:
            result = number1 / number2
    OTHERWISE:
        DISPLAY "Invalid operator!"

    DISPLAY "number1 operation number2 = result"
```

This pseudocode can't be run yet, but it already gives us a clear picture of what to write.

## Stage 3: Implementation

Now it's time to write the actual Go code. We'll build it up step by step.

### Version 1: Basic Skeleton

Start with a skeleton program that just reads input, without calculating anything yet:

```go
package main

    "bufio"
    "fmt"
    "os"
    "strconv"

    fmt.Print("Enter the operator (+, -, *, /): ")
    scanner.Scan()

    fmt.Print("Enter the second number: ")
    scanner.Scan()

    // TODO: Calculate the result
    // TODO: Display the result

    fmt.Println(number1, operation, number2)
}
```

Try running it — the program can already accept input, even though it doesn't calculate anything yet (that last line just makes sure the variables are actually used, so we don't get a "declared and not used" error).

### Version 2: Add the Calculation

Now let's add the calculation logic. We'll use `switch` — even though we haven't formally learned it yet (that's in Unit 2), the concept is pretty intuitive: "match the operation value against one of the cases, and run the matching block."

```go
package main

import (
    "bufio"
    "fmt"
    "os"
    "strconv"
)

func main() {
    scanner := bufio.NewScanner(os.Stdin)
    var result float64
    valid := true // flag for whether the operation is valid

    fmt.Println("=== SIMPLE CALCULATOR ===")
    fmt.Println()

    fmt.Print("Enter the first number: ")
    scanner.Scan()
    number1, _ := strconv.ParseFloat(scanner.Text(), 64)

    fmt.Print("Enter the operator (+, -, *, /): ")
    scanner.Scan()
    operation := scanner.Text()

    fmt.Print("Enter the second number: ")
    scanner.Scan()
    number2, _ := strconv.ParseFloat(scanner.Text(), 64)

    switch operation {
    case "+":
        result = number1 + number2
    case "-":
        result = number1 - number2
    case "*":
        result = number1 * number2
    case "/":
        if number2 == 0 {
            fmt.Println("\n[ERROR] Cannot divide by zero!")
            valid = false
        } else {
            result = number1 / number2
        }
    default:
        fmt.Printf("\n[ERROR] Operator '%s' not recognized.\n", operation)
        fmt.Println("Available operators: +, -, *, /")
        valid = false
    }

    if valid {
        fmt.Printf("\nResult: %.2f %s %.2f = %.2f\n", number1, operation, number2, result)
    }
}
```

This is our complete calculator! Let's understand the important parts.

## Understanding the Code

### Variables Used

```go
var result float64   // declared with var because it's filled in later, inside the switch
valid := true          // flag: did the operation succeed?
number1, _ := strconv.ParseFloat(scanner.Text(), 64)  // short declaration, filled immediately
```

We use `float64` (not `int`) for `number1`, `number2`, and `result` so the calculator can handle decimal numbers. `operation` is stored as `string` because that's what `scanner.Text()` returns. `valid` is a "flag" (`bool`) marking whether the calculation succeeded.

Notice `result` is declared with `var result float64` (without an initial value, so it automatically gets the zero value `0`), not `:=` — because its value is only filled in later inside the `switch` block, not right at declaration.

### The `switch` Branch

Even though we haven't formally learned this yet, the logic is simple:

```go
switch operation {
case "+":            // If operation equals "+"
    result = number1 + number2
case "-":             // Otherwise, if operation equals "-"
    result = number1 - number2
default:              // Anything else (unrecognized operator)
    // handle error
}
```

Notice: **there's no need for `break`** at the end of each `case` like in C++/Java — Go automatically stops after running the one matching `case`.

### Handling Division by Zero

```go
case "/":
    if number2 == 0 {
        fmt.Println("\n[ERROR] Cannot divide by zero!")
        valid = false
    } else {
        result = number1 / number2
    }
```

Dividing by zero on a `float64` in Go doesn't actually crash — the result is `+Inf` (infinity) or `NaN` (not a runtime error like in many other languages). But showing "Inf" to the user is confusing, so we explicitly check `number2 == 0` to give a clear message instead.

## Complete Solution Code (Final Version)

Here's the complete, cleaned-up code with comments:

```go
package main

import (
    "bufio"
    "fmt"
    "os"
    "strconv"
)

func main() {
    scanner := bufio.NewScanner(os.Stdin)

    // === Variables ===
    var result float64 // The calculation result
    valid := true        // Is the operation valid?

    // === Header ===
    fmt.Println("=============================")
    fmt.Println("     SIMPLE GO CALCULATOR   ")
    fmt.Println("=============================")
    fmt.Println()

    // === Input ===
    fmt.Print("Enter the first number  : ")
    scanner.Scan()
    number1, _ := strconv.ParseFloat(scanner.Text(), 64)

    fmt.Print("Enter the operator (+, -, *, /): ")
    scanner.Scan()
    operation := scanner.Text()

    fmt.Print("Enter the second number : ")
    scanner.Scan()
    number2, _ := strconv.ParseFloat(scanner.Text(), 64)

    // === Calculation ===
    switch operation {
    case "+":
        result = number1 + number2
    case "-":
        result = number1 - number2
    case "*":
        result = number1 * number2
    case "/":
        if number2 == 0 {
            fmt.Println("\n[ERROR] Cannot divide by zero!")
            valid = false
        } else {
            result = number1 / number2
        }
    default:
        fmt.Printf("\n[ERROR] Operator '%s' not recognized.\n", operation)
        fmt.Println("Available operators: +, -, *, /")
        valid = false
    }

    // === Output ===
    if valid {
        fmt.Println()
        fmt.Println("-----------------------------")
        fmt.Printf("  %.2f %s %.2f = %.2f\n", number1, operation, number2, result)
        fmt.Println("-----------------------------")
    }

    fmt.Println("\nThanks for using the calculator!")
}
```

Full interaction example:
```

     SIMPLE GO CALCULATOR
=============================

Enter the first number  : 12.5
Enter the operator (+, -, *, /): *
Enter the second number : 4

-----------------------------
  12.50 * 4.00 = 50.00
-----------------------------

Thanks for using the calculator!
```

## Bonus Challenge

Already done? Try these extra challenges to test your skills:

**Challenge 1: Modulo Operator**

Add support for the `%` (modulo) operator. Remember that modulo in Go only works with integers, so you'll need to convert `float64` to `int` (and remember: this conversion **truncates**, it doesn't round!):

```go
case "%":
    if number2 == 0 {
        fmt.Println("Error: cannot modulo by zero!")
        valid = false
    } else {
        result = float64(int(number1) % int(number2))
    }
```

**Challenge 2: Show Extra Information**

Before showing the result, also display extra info:
- The type of operation (Addition/Subtraction/Multiplication/Division)
- Whether the result is positive, negative, or zero

**Challenge 3: Multiple Calculations**

Wrap the whole program in a loop so the calculator can be used repeatedly without restarting. We'll formally learn `for` — Go's only loop keyword — in Unit 3, but if you're curious, try wrapping it with `for { ... }` (an infinite loop) and `break` when the user types "exit".
