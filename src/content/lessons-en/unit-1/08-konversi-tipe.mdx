# Type Conversion

Since the Data Types lesson, you've known that Go doesn't do automatic conversion. Now it's time to master how to do it **explicitly** — and learn about one trap that quietly causes bugs.

## Converting Between Numeric Types

```go
package main

import "fmt"

func main() {
    var wholeNumber int = 9
    var decimalNumber float64 = float64(wholeNumber)
    fmt.Println(decimalNumber)  // 9

    var pi float64 = 3.99
    var piInt int = int(pi)
    fmt.Println(piInt)  // 3 — not 4!
}
```

Output:
```
9
3
```

## Breaking Down Numeric Conversion

**`float64(wholeNumber)`** — converts an `int` to `float64`. Safe, no data is lost.

**`int(pi)`** — converts a `float64` to `int`. Notice the result is `3`, even though `3.99` "should" round to `4`. Converting `float64` to `int` in Go **always truncates** the decimal part, **never rounds**.

:::note
If you actually need mathematical rounding (not truncation), use a function from the `math` package: `math.Round()`, `math.Ceil()` (rounds up), or `math.Floor()` (rounds down, same as truncation for positive numbers).
:::

## Converting String ↔ Number

Converting to/from `string` is a bit different — you can't use `int(...)` or `float64(...)` directly, you have to go through the `strconv` package.

```go
package main

import (
    "fmt"
    "strconv"
)

func main() {
    // Number to string
    age := 17
    ageText := strconv.Itoa(age)
    fmt.Println("You are: " + ageText + " years old")

    // String to number
    input := "42"
    number, err := strconv.Atoi(input)
    if err != nil {
        fmt.Println("Conversion failed:", err)
        return
    }
    fmt.Println(number + 8)

    // String to float64
    decimalInput := "3.14"
    decimal, _ := strconv.ParseFloat(decimalInput, 64)
    fmt.Println(decimal * 2)
}
```

Output:
```
You are: 17 years old
50
6.28
```

## Breaking Down the strconv Functions

**`strconv.Itoa(age)`** — "**I**nteger **to** **A**SCII", converts an `int` to a `string`. Only needs one argument, and it never fails (doesn't return an error).

**`strconv.Atoi(input)`** — the reverse, "**A**SCII **to** **I**nteger". **Can fail** (e.g. if `input` isn't a valid number), which is why it returns two values: the result and an `error`.

**`strconv.ParseFloat(decimalInput, 64)`** — converts a `string` to `float64`. The second argument (`64`) specifies bit precision — always use `64` unless you have a specific reason not to.

:::tip
An alternative for inserting numbers into a string is `fmt.Sprintf`, which works like `Printf` but returns a `string` instead of printing directly:
```go
message := fmt.Sprintf("You are: %d years old", age)
```
This is often more concise than `strconv.Itoa` plus manual `+` concatenation.
:::

## Common Mistakes

1. **Ignoring the error from Atoi/ParseFloat:**
   ```go
   number, _ := strconv.Atoi("not-a-number")
   fmt.Println(number)  // 0, with no clear error message if _ is ignored
   ```
   Always check `err` unless you're 100% sure the input is valid.

2. **Assuming `int(3.99)` rounds to 4:**
   ```go
   result := int(3.99)
   fmt.Println(result)  // 3, NOT 4 — Go truncates, it doesn't round
   ```
   Use `math.Round(3.99)` if you need actual mathematical rounding.

3. **Using `int()`/`float64()` to convert from a string:**
   ```go
   number := int("42")  // ERROR: cannot convert "42" (untyped string constant) to type int
   ```
   Converting a string to a number **must** go through `strconv` — you can't use `int(...)` directly.

## Summary

| Conversion | How | Can Fail? |
|---|---|---|
| int → float64 | `float64(x)` | No |
| float64 → int | `int(x)` (truncates, doesn't round!) | No |
| int → string | `strconv.Itoa(x)` | No |
| string → int | `strconv.Atoi(s)` | Yes (returns error) |
| string → float64 | `strconv.ParseFloat(s, 64)` | Yes (returns error) |
