# JSON Encoding

JSON is the most common data-exchange format on the web — used by REST APIs, config files, even messages between microservices. Go has built-in JSON support through the `encoding/json` package, and it fits neatly together with the `struct` type you've mastered since Unit 6.

## Struct to JSON: json.Marshal

```go
package main

import (
    "encoding/json"
    "fmt"
)

type Student struct {
    Name   string
    Age    int
    Active bool
}

func main() {
    student := Student{Name: "Budi", Age: 17, Active: true}

    data, err := json.Marshal(student)
    if err != nil {
        fmt.Println("Encode failed:", err)
        return
    }

    fmt.Println(string(data))
}
```

Output:
```
{"Name":"Budi","Age":17,"Active":true}
```

## Breaking Down json.Marshal

**`json.Marshal(student)`** — converts a Go value (here, the `Student` struct) into JSON. It returns **two values**: `[]byte` (the JSON data as bytes) and `error`.

**`string(data)`** — `Marshal` returns `[]byte`, not `string`, so it needs an explicit conversion to display as text — a type conversion pattern you've known since Unit 1.

**The JSON field names match the struct field names exactly** (`Name`, `Age`, `Active`) — because the fields are exported (capitalized). If you want different JSON names (say, lowercase, or the `snake_case` style more common in JSON), you need a **struct tag**.

## Controlling Field Names with Struct Tags

```go
type Student struct {
    Name   string `json:"name"`
    Age    int    `json:"age"`
    Active bool   `json:"active"`
}
```

With this struct tag, the result of `json.Marshal` becomes:
```
{"name":"Budi","age":17,"active":true}
```

A struct tag is written inside backticks, `` `json:"name"` ``, right after the field's type. This isn't an ordinary comment — Go reads this text through reflection when `Marshal`/`Unmarshal` runs.

:::note
Struct fields **must be exported** (capitalized) to be encoded into JSON at all — this is a direct continuation of the exported/unexported rule you learned in this unit's first lesson. Unexported fields (lowercase) are **silently skipped**, with no error.
:::

## JSON to Struct: json.Unmarshal

The reverse — turning JSON text into a Go struct:

```go
package main

import (
    "encoding/json"
    "fmt"
)

type Student struct {
    Name string `json:"name"`
    Age  int    `json:"age"`
}

func main() {
    jsonText := `{"name": "Ani", "age": 16}`

    var student Student
    err := json.Unmarshal([]byte(jsonText), &student)
    if err != nil {
        fmt.Println("Decode failed:", err)
        return
    }

    fmt.Println(student.Name, student.Age)
}
```

Output:
```
Ani 16
```

## Breaking Down json.Unmarshal

**`` `{"name": "Ani", "age": 16}` ``** — a backtick string literal (raw string), handy for text with lots of double quotes that would otherwise need escaping one by one.

**`var student Student`** — declare an empty variable first (zero value: `Name` = `""`, `Age` = `0`), which `Unmarshal` will then **fill in**.

**`json.Unmarshal([]byte(jsonText), &student)`** — notice the `&` before `student`! `Unmarshal` needs the **address (pointer)** of the target variable, because it needs to **modify `student`'s contents directly**, not just return a new value. You've known the pointer concept since Unit 6 (pointer receivers).

:::tip
You can add `,omitempty` to a struct tag (`json:"name,omitempty"`) so a field with a zero value (`""`, `0`, `false`) is left out of the JSON output entirely. Useful for optional fields.
:::

## Common Mistakes

1. **Forgetting `&` when calling Unmarshal:**
   ```go
   var student Student
   json.Unmarshal([]byte(jsonText), student)  // ERROR: json: Unmarshal(non-pointer main.Student)
   ```
   `Unmarshal` always needs a pointer as its second argument, so it can fill in the original variable.

2. **Assuming an unexported field gets encoded too:**
   ```go
   type Student struct {
       name string  // unexported — will NOT show up in the JSON
   }
   // json.Marshal(student) produces: {}
   ```
   If a field doesn't show up in the `Marshal` result, check first: is its first letter capitalized?

## Summary

| Function | Direction | Return |
|---|---|---|
| `json.Marshal(v)` | Go → JSON | `([]byte, error)` |
| `json.Unmarshal(data, &v)` | JSON → Go | `error` (fills `v` via pointer) |
| `` `json:"name"` `` | Struct tag | Controls a field's name in JSON |
| `` `json:"name,omitempty"` `` | Struct tag | Hides a field when it's a zero value |
