# Interface

This is one of Go's most distinctive features. In many languages (Java, C#), a type must **explicitly** declare `implements InterfaceName`. In Go, **there's no such step at all** — a type automatically satisfies an interface simply by implementing all the methods it requires. This is called **implicit interface satisfaction**, and it changes how you design programs in Go.

## Declaring and Satisfying an Interface

```go
package main

import "fmt"

type Shape interface {
    Area() float64
}

type Square struct {
    Side float64
}

func (s Square) Area() float64 {
    return s.Side * s.Side
}

type Circle struct {
    Radius float64
}

func (c Circle) Area() float64 {
    return 3.14 * c.Radius * c.Radius
}

func printArea(s Shape) {
    fmt.Printf("Area: %.2f\n", s.Area())
}

func main() {
    sq := Square{Side: 4}
    c := Circle{Radius: 3}

    printArea(sq)
    printArea(c)
}
```

Output:
```
Area: 16.00
Area: 28.26
```

## Breaking Down the Interface

**`type Shape interface { Area() float64 }`** — declares an interface type named `Shape`. Its contents are just **method signatures** (name, parameters, return type) — no body, no fields.

**`Square` and `Circle`** — look closely: **there isn't a single line** saying "Square implements Shape". Both structs automatically satisfy the `Shape` interface simply because each has an `Area() float64` method with exactly the same signature the interface requires.

Picture an interface like a job posting that only lists a requirement: "can drive a car". Anyone who has that ability automatically "qualifies" — no matter their background, and with no need to formally register as a "qualifier".

**`func printArea(s Shape)`** — the parameter `s` is of interface type `Shape`, not a concrete struct type. This means the function can accept **a value of any type**, as long as that type has an `Area() float64` method. This is the power of interfaces: one function can work with many different types, as long as its method "contract" is satisfied.

:::tip
This principle is sometimes called the static version of *duck typing*: "if it walks like a duck and quacks like a duck, treat it as a duck" — but in Go, all of this is still strictly checked at compile time, not at runtime like in Python.
:::

## The Empty Interface

An interface with no methods at all, written `interface{}`, can hold a value **of any type** — because its requirement is empty, every type automatically satisfies it.

```go
func printAnything(v interface{}) {
    fmt.Println(v)
}

func main() {
    printAnything(42)
    printAnything("hello")
    printAnything(true)
}
```

Output:
```
42
hello
true
```

:::warning
Always write `interface{}` literally as shown above for the empty interface. The Go version used in this course (and many production projects) doesn't yet support the `any` alias — that feature only arrived in Go 1.18 and later.
:::

:::note
A method signature must match **exactly** — including parameter types and return type. If `Area()` returns `int` when the interface requires `float64`, that type does **not** satisfy the interface, even though the name matches.
:::

## Common Mistakes

1. **A method's return type doesn't match the interface:**
   ```go
   func (s Square) Area() int { // should be float64
       return int(s.Side * s.Side)
   }

   func main() {
       var sh Shape = Square{Side: 4}
       // ERROR: cannot use Square{...} (type Square) as type Shape:
       // Square does not implement Shape (wrong type for Area method)
   }
   ```

2. **A method is declared with a pointer receiver, but used through a value:**
   ```go
   type Triangle struct {
       Base, Height float64
   }

   func (t *Triangle) Area() float64 {
       return t.Base * t.Height / 2
   }

   func main() {
       var sh Shape = Triangle{Base: 4, Height: 3}
       // ERROR: cannot use Triangle{...} (type Triangle) as type Shape:
       // Triangle does not implement Shape (Area method has pointer receiver)
   }
   ```
   If a method uses a pointer receiver, only `*Triangle` satisfies the interface, not plain `Triangle`. The fix: `var sh Shape = &Triangle{Base: 4, Height: 3}`.

## Summary

| Concept | Example |
|---|---|
| Interface declaration | `type Shape interface { Area() float64 }` |
| Implicit satisfaction | Just implement the method, no `implements` needed |
| Parameter of interface type | `func printArea(s Shape)` |
| The empty interface | `func printAnything(v interface{})` |
| Pointer receiver gotcha | Only `*Type` satisfies the interface if the method uses a pointer receiver |
