# JSON Encoding

JSON adalah format tukar-data paling umum di web — dipakai REST API, file konfigurasi, sampai pesan antar microservice. Go punya dukungan JSON bawaan lewat package `encoding/json`, dan strukturnya menyatu rapi dengan `struct` yang sudah kamu kuasai sejak Unit 6.

## Struct ke JSON: json.Marshal

```go
package main

import (
    "encoding/json"
    "fmt"
)

type Siswa struct {
    Nama  string
    Umur  int
    Aktif bool
}

func main() {
    siswa := Siswa{Nama: "Budi", Umur: 17, Aktif: true}

    data, err := json.Marshal(siswa)
    if err != nil {
        fmt.Println("Gagal encode:", err)
        return
    }

    fmt.Println(string(data))
}
```

Output:
```
{"Nama":"Budi","Umur":17,"Aktif":true}
```

## Membedah json.Marshal

**`json.Marshal(siswa)`** — mengonversi nilai Go (di sini, struct `Siswa`) menjadi JSON. Mengembalikan **dua nilai**: `[]byte` (data JSON dalam bentuk byte) dan `error`.

**`string(data)`** — `Marshal` mengembalikan `[]byte`, bukan `string`, jadi perlu dikonversi eksplisit untuk ditampilkan sebagai teks — pola konversi tipe yang sudah kamu kenal sejak Unit 1.

**Nama field di JSON sama persis dengan nama field struct** (`Nama`, `Umur`, `Aktif`) — karena field-nya exported (kapital). Kalau kamu ingin nama JSON berbeda (misalnya huruf kecil, gaya `snake_case` yang lebih umum di JSON), kamu butuh **struct tag**.

## Mengatur Nama Field dengan Struct Tag

```go
type Siswa struct {
    Nama  string `json:"nama"`
    Umur  int    `json:"umur"`
    Aktif bool   `json:"aktif"`
}
```

Dengan struct tag ini, hasil `json.Marshal` menjadi:
```
{"nama":"Budi","umur":17,"aktif":true}
```

Struct tag ditulis di dalam backtick `` `json:"nama"` `` setelah tipe field. Ini bukan komentar biasa — Go membaca teks ini lewat reflection saat `Marshal`/`Unmarshal` dijalankan.

:::note
Field struct **wajib exported** (huruf kapital) supaya bisa di-encode ke JSON sama sekali — ini kelanjutan langsung dari aturan exported/unexported yang kamu pelajari di lesson pertama unit ini. Field unexported (huruf kecil) akan **dilewati diam-diam**, tanpa error.
:::

## JSON ke Struct: json.Unmarshal

Kebalikannya — mengubah teks JSON menjadi struct Go:

```go
package main

import (
    "encoding/json"
    "fmt"
)

type Siswa struct {
    Nama string `json:"nama"`
    Umur int    `json:"umur"`
}

func main() {
    jsonText := `{"nama": "Ani", "umur": 16}`

    var siswa Siswa
    err := json.Unmarshal([]byte(jsonText), &siswa)
    if err != nil {
        fmt.Println("Gagal decode:", err)
        return
    }

    fmt.Println(siswa.Nama, siswa.Umur)
}
```

Output:
```
Ani 16
```

## Membedah json.Unmarshal

**`` `{"nama": "Ani", "umur": 16}` ``** — string literal pakai backtick (raw string), praktis untuk teks yang mengandung banyak tanda kutip ganda tanpa perlu di-escape satu-satu.

**`var siswa Siswa`** — deklarasikan variabel kosong dulu (zero value: `Nama` = `""`, `Umur` = `0`) yang nanti akan **diisi** oleh `Unmarshal`.

**`json.Unmarshal([]byte(jsonText), &siswa)`** — perhatikan tanda `&` sebelum `siswa`! `Unmarshal` butuh **alamat (pointer)** ke variabel tujuan, karena fungsi ini perlu **mengubah isi `siswa` secara langsung**, bukan cuma mengembalikan nilai baru. Konsep pointer sudah kamu kenal sejak Unit 6 (pointer receiver).

:::tip
Kamu bisa menambahkan `,omitempty` di struct tag (`json:"nama,omitempty"`) supaya field dengan zero value (`""`, `0`, `false`) tidak dimasukkan sama sekali ke output JSON. Berguna untuk field opsional.
:::

## Kesalahan Umum

1. **Lupa `&` saat Unmarshal:**
   ```go
   var siswa Siswa
   json.Unmarshal([]byte(jsonText), siswa)  // ERROR: json: Unmarshal(non-pointer main.Siswa)
   ```
   `Unmarshal` selalu butuh pointer sebagai argumen kedua, supaya bisa mengisi variabel aslinya.

2. **Field unexported dikira ikut ter-encode:**
   ```go
   type Siswa struct {
       nama string  // unexported — TIDAK akan muncul di JSON
   }
   // json.Marshal(siswa) menghasilkan: {}
   ```
   Kalau field-nya tidak muncul di hasil `Marshal`, cek dulu: apakah huruf pertamanya kapital?

## Ringkasan

| Fungsi | Arah | Return |
|---|---|---|
| `json.Marshal(v)` | Go → JSON | `([]byte, error)` |
| `json.Unmarshal(data, &v)` | JSON → Go | `error` (mengisi `v` lewat pointer) |
| `` `json:"nama"` `` | Struct tag | Mengatur nama field di JSON |
| `` `json:"nama,omitempty"` `` | Struct tag | Sembunyikan field kalau zero value |
