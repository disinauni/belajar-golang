# Input & Output

Program yang cuma mencetak teks tetap itu membosankan — program sungguhan berinteraksi dengan penggunanya. Di Go, membaca input dari keyboard sedikit lebih verbose dibanding bahasa seperti Python, tapi begitu kamu paham polanya, kamu akan memakainya berulang-ulang.

## Membaca Input dengan bufio.Scanner

```go
package main

import (
    "bufio"
    "fmt"
    "os"
)

func main() {
    scanner := bufio.NewScanner(os.Stdin)

    fmt.Print("Siapa namamu? ")
    scanner.Scan()
    nama := scanner.Text()

    fmt.Println("Halo, " + nama + "!")
}
```

Kalau kamu jalankan ini di halaman **Playground** (buka kolom "Input/stdin" dan isi nama sebelum klik Run) dan mengetik `Budi`, outputnya:

```
Siapa namamu? Halo, Budi!
```

## Membedah Setiap Baris

**`import ( "bufio" "fmt" "os" )`** — kali ini kita import tiga package sekaligus, ditulis dalam kurung. Ini gaya penulisan import yang direkomendasikan saat lebih dari satu package dipakai.

**`bufio.NewScanner(os.Stdin)`** — membuat scanner baru yang membaca dari `os.Stdin`, yaitu "standard input" — biasanya keyboard. `bufio` (buffered I/O) menyediakan cara efisien membaca input baris per baris.

**`scanner.Scan()`** — membaca satu baris input, menunggu sampai pengguna menekan Enter. Fungsi ini mengembalikan `bool`: `true` kalau berhasil membaca sesuatu.

**`scanner.Text()`** — mengambil teks yang baru saja dibaca `Scan()`, sebagai `string`.

:::note
Kotak **Latihan** di pelajaran ini tidak menyediakan kolom stdin, jadi kode yang butuh input interaktif sebaiknya kamu coba dulu di halaman **Playground** (yang punya kolom "Input/stdin"), bukan di kotak Latihan di bawah.
:::

## Membaca Angka dari Input

`scanner.Text()` selalu mengembalikan `string` — bahkan kalau penggunanya mengetik angka. Untuk mengubahnya jadi angka, kita perlu package `strconv` (string conversion):

```go
package main

import (
    "bufio"
    "fmt"
    "os"
    "strconv"
)

func main() {
    scanner := bufio.NewScanner(os.Stdin)

    fmt.Print("Umurmu berapa? ")
    scanner.Scan()
    teksUmur := scanner.Text()

    umur, err := strconv.Atoi(teksUmur)
    if err != nil {
        fmt.Println("Itu bukan angka yang valid!")
        return
    }

    fmt.Printf("Tahun depan kamu %d tahun.\n", umur+1)
}
```

## Membedah Konversi Angka

**`strconv.Atoi(teksUmur)`** — "Atoi" singkatan dari "ASCII to Integer". Fungsi ini mencoba mengubah string jadi `int`, dan mengembalikan **dua nilai**: hasil konversi (`int`) dan `error` (nil kalau berhasil, berisi pesan kalau gagal).

**`if err != nil { ... }`** — pola idiomatik Go untuk memeriksa error. Kalau `err` bukan `nil`, artinya konversi gagal (misalnya penggunanya mengetik "abc" bukan angka). Kita bahas error handling secara lengkap di Unit 6 — untuk sekarang, cukup ingat pola ini sering muncul.

**`fmt.Printf("Tahun depan kamu %d tahun.\n", umur+1)`** — `Printf` memakai *format verb* seperti `%d` (integer) untuk menyisipkan nilai ke dalam teks. Perhatikan juga `\n` di akhir — beda dari `Println`, `Printf` **tidak** otomatis menambahkan baris baru, jadi kamu harus menulisnya sendiri.

:::tip
Format verb yang sering dipakai: `%d` untuk integer, `%s` untuk string, `%f` untuk desimal (`%.2f` untuk 2 angka di belakang koma), `%t` untuk bool, `%v` untuk nilai apapun (format default).
:::

## Kesalahan Umum

1. **Lupa import `bufio` atau `os`:**
   ```go
   scanner := bufio.NewScanner(os.Stdin)  // ERROR: undefined: bufio (kalau lupa import)
   ```

2. **Lupa menangani error dari strconv.Atoi:**
   ```go
   umur, _ := strconv.Atoi(teksUmur)  // error diabaikan dengan _
   fmt.Println(umur + 1)  // kalau input bukan angka, umur bernilai 0 — bukan error yang jelas!
   ```
   Mengabaikan error dengan `_` kadang oke untuk contoh singkat, tapi program yang serius sebaiknya selalu memeriksa `err`.

3. **Lupa `\n` di `Printf`:**
   ```go
   fmt.Printf("Halo, %s!", nama)  // tidak ada baris baru di akhir
   fmt.Println("Baris berikutnya")
   // Output: Halo, Budi!Baris berikutnya  ← nempel!
   ```

## Ringkasan

| Konsep | Contoh |
|---|---|
| Buat scanner | `bufio.NewScanner(os.Stdin)` |
| Baca satu baris | `scanner.Scan()` |
| Ambil teksnya | `scanner.Text()` |
| String ke int | `strconv.Atoi(teks)` (return: int, error) |
| Format output | `fmt.Printf("%d %s %.2f\n", ...)` |
