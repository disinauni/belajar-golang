# Konversi Tipe Data

Sejak pelajaran Tipe Data, kamu sudah tahu Go tidak melakukan konversi otomatis. Sekarang saatnya kuasai cara melakukannya **secara eksplisit** — dan mengenal satu jebakan yang sering bikin bug diam-diam.

## Konversi Antar Tipe Numerik

```go
package main

import "fmt"

func main() {
    var bilanganBulat int = 9
    var bilanganDesimal float64 = float64(bilanganBulat)
    fmt.Println(bilanganDesimal)  // 9

    var pi float64 = 3.99
    var piBulat int = int(pi)
    fmt.Println(piBulat)  // 3 — bukan 4!
}
```

Output:
```
9
3
```

## Membedah Konversi Numerik

**`float64(bilanganBulat)`** — mengonversi `int` ke `float64`. Aman, tidak ada data yang hilang.

**`int(pi)`** — mengonversi `float64` ke `int`. Perhatikan hasilnya `3`, padahal `3.99` "harusnya" dibulatkan jadi `4`. Konversi `float64` ke `int` di Go **selalu memotong (truncate)** bagian desimal, **tidak pernah membulatkan**.

:::note
Kalau kamu benar-benar butuh pembulatan matematis (bukan pemotongan), pakai fungsi dari package `math`: `math.Round()`, `math.Ceil()` (bulatkan ke atas), atau `math.Floor()` (bulatkan ke bawah, sama seperti pemotongan untuk angka positif).
:::

## Konversi String ↔ Angka

Konversi ke/dari `string` sedikit berbeda — tidak bisa pakai `int(...)` atau `float64(...)` langsung, harus lewat package `strconv`.

```go
package main

import (
    "fmt"
    "strconv"
)

func main() {
    // Angka ke string
    umur := 17
    teksUmur := strconv.Itoa(umur)
    fmt.Println("Umurmu: " + teksUmur + " tahun")

    // String ke angka
    input := "42"
    angka, err := strconv.Atoi(input)
    if err != nil {
        fmt.Println("Gagal konversi:", err)
        return
    }
    fmt.Println(angka + 8)

    // String ke float64
    inputDesimal := "3.14"
    desimal, _ := strconv.ParseFloat(inputDesimal, 64)
    fmt.Println(desimal * 2)
}
```

Output:
```
Umurmu: 17 tahun
50
6.28
```

## Membedah Fungsi strconv

**`strconv.Itoa(umur)`** — "**I**nteger **to** **A**SCII", mengubah `int` jadi `string`. Cuma butuh satu argumen, tidak pernah gagal (tidak mengembalikan error).

**`strconv.Atoi(input)`** — kebalikannya, "**A**SCII **to** **I**nteger". **Bisa gagal** (misalnya kalau `input` bukan angka valid), makanya mengembalikan dua nilai: hasil dan `error`.

**`strconv.ParseFloat(inputDesimal, 64)`** — mengubah `string` jadi `float64`. Argumen kedua (`64`) menentukan presisi bit — selalu pakai `64` kecuali kamu punya alasan spesifik.

:::tip
Alternatif untuk menggabungkan angka ke dalam string adalah `fmt.Sprintf`, yang bekerja seperti `Printf` tapi mengembalikan `string` alih-alih mencetak langsung:
```go
pesan := fmt.Sprintf("Umurmu: %d tahun", umur)
```
Ini sering lebih ringkas daripada `strconv.Itoa` + penggabungan `+` manual.
:::

## Kesalahan Umum

1. **Mengabaikan error dari Atoi/ParseFloat:**
   ```go
   angka, _ := strconv.Atoi("bukan-angka")
   fmt.Println(angka)  // 0, tanpa pesan error yang jelas kalau _ diabaikan
   ```
   Selalu periksa `err` kecuali kamu yakin 100% inputnya valid.

2. **Mengira `int(3.99)` membulatkan jadi 4:**
   ```go
   hasil := int(3.99)
   fmt.Println(hasil)  // 3, BUKAN 4 — Go memotong, tidak membulatkan
   ```
   Pakai `math.Round(3.99)` kalau kamu butuh pembulatan matematis sesungguhnya.

3. **Memakai `int()`/`float64()` untuk konversi dari string:**
   ```go
   angka := int("42")  // ERROR: cannot convert "42" (untyped string constant) to type int
   ```
   Konversi string ke angka **wajib** lewat `strconv`, tidak bisa pakai `int(...)` langsung.

## Ringkasan

| Konversi | Cara | Bisa Gagal? |
|---|---|---|
| int → float64 | `float64(x)` | Tidak |
| float64 → int | `int(x)` (memotong, bukan membulatkan!) | Tidak |
| int → string | `strconv.Itoa(x)` | Tidak |
| string → int | `strconv.Atoi(s)` | Ya (return error) |
| string → float64 | `strconv.ParseFloat(s, 64)` | Ya (return error) |
