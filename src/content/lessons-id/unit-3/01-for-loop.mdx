# For Loop

Kalau kamu pernah lihat kode dari bahasa lain, kamu tahu ada `for`, `while`, dan `do-while`. Go menyederhanakan semuanya jadi **satu keyword saja: `for`**. Jangan salah — ini bukan Go "kurang fitur", justru ini keputusan desain yang sengaja membuat Go lebih sederhana dipelajari.

## Bentuk 1: For dengan Tiga Klausa

Ini bentuk paling mirip bahasa lain — kalau kamu pernah pakai `for (int i=0; i<n; i++)` di C++/Java, ini polanya:

```go
package main

import "fmt"

func main() {
    for i := 0; i < 5; i++ {
        fmt.Println("Perulangan ke-", i)
    }
}
```

Output:
```
Perulangan ke- 0
Perulangan ke- 1
Perulangan ke- 2
Perulangan ke- 3
Perulangan ke- 4
```

## Membedah Tiga Klausa

**`i := 0`** — klausa **init**, dijalankan sekali di awal, sebelum loop dimulai.

**`i < 5`** — klausa **kondisi**, dicek sebelum setiap iterasi. Loop terus berjalan selama ini `true`.

**`i++`** — klausa **post**, dijalankan setelah setiap iterasi selesai.

Sama seperti `if`, perhatikan **tidak ada tanda kurung** di sekitar ketiga klausa — hanya dipisah titik koma, dan kurung kurawal `{}` tetap wajib.

## Bentuk 2: For sebagai While

Kalau kamu cuma butuh kondisi tanpa init/post eksplisit, cukup tulis kondisinya saja:

```go
package main

import "fmt"

func main() {
    n := 1
    for n <= 16 {
        fmt.Println(n)
        n *= 2
    }
}
```

Output:
```
1
2
4
8
16
```

Ini setara dengan `while (n <= 16)` di bahasa lain — Go tidak butuh keyword terpisah, cukup `for` dengan satu kondisi.

## Bentuk 3: Infinite Loop

Tanpa klausa apapun, `for` menjadi loop tak terhingga — berguna kalau kamu ingin mengontrol keluarnya lewat `break` di tengah blok:

```go
package main

import "fmt"

func main() {
    hitung := 0
    for {
        hitung++
        fmt.Println("Iterasi:", hitung)
        if hitung >= 3 {
            break
        }
    }
}
```

Output:
```
Iterasi: 1
Iterasi: 2
Iterasi: 3
```

**`for {`** — tanpa kondisi sama sekali berarti "selalu true", jadi loop akan berjalan selamanya kecuali ada `break` (atau `return`) di dalamnya.

:::note
Ini pola yang sering dipakai untuk server yang harus terus "mendengarkan" request, atau game yang terus berjalan sampai pemain keluar. Kamu akan sering melihat `for { ... }` di kode Go dunia nyata.
:::

:::tip
Go tidak punya `do-while` (loop yang badan-nya dijalankan minimal sekali sebelum cek kondisi). Kalau kamu butuh perilaku itu, gunakan pola: jalankan badan loop sekali di luar, lalu bungkus sisanya dengan `for kondisi { ... }`, atau pakai infinite loop dengan pengecekan kondisi + `break` di akhir badan loop.
:::

## Kesalahan Umum

1. **Menambahkan tanda kurung di sekitar klausa:**
   ```go
   for (i := 0; i < 5; i++) {  // ERROR: syntax error
       fmt.Println(i)
   }
   ```
   Sama seperti `if`, tanda kurung di sekitar klausa `for` **tidak valid** di Go.

2. **Lupa `break` di infinite loop, program tidak pernah berhenti:**
   ```go
   for {
       fmt.Println("Ini akan tercetak selamanya...")
       // lupa break!
   }
   ```
   Selalu pastikan ada jalan keluar (`break` atau `return`) di infinite loop, kalau tidak program akan macet (atau di playground: timeout).

3. **Lupa update variabel di bentuk while-style, jadi infinite loop tidak sengaja:**
   ```go
   n := 1
   for n <= 5 {
       fmt.Println(n)
       // lupa n++  → loop selamanya!
   }
   ```

## Ringkasan

| Bentuk | Contoh | Setara dengan |
|---|---|---|
| Tiga klausa | `for i := 0; i < n; i++ { ... }` | for klasik |
| Kondisi saja | `for kondisi { ... }` | while |
| Tanpa klausa | `for { ... }` | while(true), butuh break |

Di pelajaran berikutnya, kita akan bahas **range** — cara ringkas mengiterasi slice, string, dan map tanpa perlu index manual!
