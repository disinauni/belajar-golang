# Project: Pola Bintang

Kamu sudah menguasai semua bentuk perulangan Go: `for` dalam tiga variasinya, `range`, `break`/`continue`/label, dan nested loop. Saatnya menggabungkan semuanya jadi satu program nyata — **generator pola bintang** yang bisa mencetak beberapa jenis pola sekaligus.

## Spesifikasi Program

Program kita harus bisa:

1. Meminta user memasukkan **ukuran pola** (jumlah baris)
2. Meminta user memilih **jenis pola**: segitiga siku-siku, segitiga terbalik, atau piramida
3. Mencetak pola yang dipilih sesuai ukuran

Contoh interaksi yang diharapkan (ukuran 4, pilihan segitiga):
```
=== GENERATOR POLA BINTANG ===

Masukkan ukuran pola: 4
Pilih pola (1=Segitiga, 2=Segitiga Terbalik, 3=Piramida): 1

*
**
***
****
```

## Tahap 1: Planning

**Data apa yang perlu disimpan?**
- Ukuran pola (jumlah baris — `int`)
- Pilihan jenis pola (`int` atau `string`)

**Alur program:**
1. Tampilkan judul
2. Minta input ukuran
3. Minta input pilihan pola
4. Cetak pola sesuai pilihan dengan nested loop
5. Kalau pilihan tidak valid, tampilkan pesan error

**Edge case yang perlu dipikirkan:**
- Bagaimana kalau ukuran yang dimasukkan 0 atau negatif?
- Bagaimana kalau pilihan pola bukan 1, 2, atau 3?

### Versi 2: Tambahkan Logika Pola

Sekarang tambahkan logika pencetakan untuk ketiga jenis pola, memakai `switch`:

```go
package main

import (
    "bufio"
    "fmt"
    "os"
    "strconv"
    "strings"
)

func main() {
    scanner := bufio.NewScanner(os.Stdin)

    fmt.Println("=== GENERATOR POLA BINTANG ===")
    fmt.Println()

    fmt.Print("Masukkan ukuran pola: ")
    scanner.Scan()
    ukuran, _ := strconv.Atoi(scanner.Text())

    if ukuran <= 0 {
        fmt.Println("Ukuran harus lebih dari 0!")
        return
    }

    fmt.Print("Pilih pola (1=Segitiga, 2=Segitiga Terbalik, 3=Piramida): ")
    scanner.Scan()
    pilihan, _ := strconv.Atoi(scanner.Text())

    fmt.Println()

    switch pilihan {
    case 1:
        for baris := 1; baris <= ukuran; baris++ {
            fmt.Println(strings.Repeat("*", baris))
        }
    case 2:
        for baris := ukuran; baris >= 1; baris-- {
            fmt.Println(strings.Repeat("*", baris))
        }
    case 3:
        for baris := 1; baris <= ukuran; baris++ {
            spasi := strings.Repeat(" ", ukuran-baris)
            bintang := strings.Repeat("*", 2*baris-1)
            fmt.Println(spasi + bintang)
        }
    default:
        fmt.Println("Pilihan tidak valid! Gunakan 1, 2, atau 3.")
    }
}
```

Ini adalah versi lengkap generator pola kita! Mari kita pahami bagian-bagian pentingnya.

## Memahami Kode

### strings.Repeat Menggantikan Nested Loop Manual

```go
fmt.Println(strings.Repeat("*", baris))
```

Alih-alih menulis nested loop manual untuk mencetak `baris` bintang satu per satu, kita pakai `strings.Repeat("*", baris)` yang mengembalikan string berisi karakter `"*"` diulang sebanyak `baris` kali. Ini tetap "nested" secara konsep (loop luar untuk baris, "loop dalam" digantikan `strings.Repeat`), tapi kodenya lebih ringkas dan mudah dibaca.

### Piramida: Kombinasi Spasi + Bintang

```go
spasi := strings.Repeat(" ", ukuran-baris)
bintang := strings.Repeat("*", 2*baris-1)
fmt.Println(spasi + bintang)
```

Piramida butuh dua bagian per baris: spasi di kiri (biar bintangnya rata tengah) dan bintang di tengah. Untuk `baris` ke-1 dari `ukuran=4`: spasi `4-1=3`, bintang `2*1-1=1`. Untuk `baris` ke-4: spasi `4-4=0`, bintang `2*4-1=7`. Coba hitung manual di kertas kalau belum yakin polanya!

### Segitiga Terbalik: Loop Mundur

```go
for baris := ukuran; baris >= 1; baris-- {
```

Perhatikan `for` di sini dimulai dari `ukuran` dan **mengurang** (`baris--`) sampai `1`. Ini kebalikan dari loop biasa yang naik — Go tidak peduli arahnya, `for` cukup fleksibel untuk kedua arah.

## Kode Solusi Lengkap (Final Version)

```go
package main

import (
    "bufio"
    "fmt"
    "os"
    "strconv"
    "strings"
)

func main() {
    scanner := bufio.NewScanner(os.Stdin)

    // === Header ===
    fmt.Println("=============================")
    fmt.Println("  GENERATOR POLA BINTANG GO  ")
    fmt.Println("=============================")
    fmt.Println()

    // === Input ===
    fmt.Print("Masukkan ukuran pola: ")
    scanner.Scan()
    ukuran, err := strconv.Atoi(scanner.Text())
    if err != nil || ukuran <= 0 {
        fmt.Println("\n[ERROR] Ukuran harus berupa angka lebih dari 0!")
        return
    }

    fmt.Print("Pilih pola (1=Segitiga, 2=Segitiga Terbalik, 3=Piramida): ")
    scanner.Scan()
    pilihan, _ := strconv.Atoi(scanner.Text())

    fmt.Println()

    // === Cetak Pola ===
    switch pilihan {
    case 1:
        for baris := 1; baris <= ukuran; baris++ {
            fmt.Println(strings.Repeat("*", baris))
        }
    case 2:
        for baris := ukuran; baris >= 1; baris-- {
            fmt.Println(strings.Repeat("*", baris))
        }
    case 3:
        for baris := 1; baris <= ukuran; baris++ {
            spasi := strings.Repeat(" ", ukuran-baris)
            bintang := strings.Repeat("*", 2*baris-1)
            fmt.Println(spasi + bintang)
        }
    default:
        fmt.Println("[ERROR] Pilihan tidak valid! Gunakan 1, 2, atau 3.")
        return
    }

    fmt.Println("\nTerima kasih telah menggunakan generator pola!")
}
```
