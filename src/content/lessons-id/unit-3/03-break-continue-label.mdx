# Break, Continue & Label

Kamu sudah memakai `break` sekilas di pelajaran For Loop. Sekarang mari kuasai `break`, pasangannya `continue`, dan satu trik khusus Go untuk loop bersarang: **label**.

## Break: Menghentikan Loop

```go
package main

import "fmt"

func main() {
    for i := 1; i <= 10; i++ {
        if i == 5 {
            break
        }
        fmt.Println(i)
    }
    fmt.Println("Loop selesai")
}
```

Output:
```
1
2
3
4
Loop selesai
```

**`break`** langsung menghentikan loop **sepenuhnya**, melompat ke baris setelah loop berakhir. Perhatikan angka `5` tidak pernah tercetak — begitu `i == 5`, loop langsung berhenti.

## Continue: Melompati Satu Iterasi

```go
package main

import "fmt"

func main() {
    for i := 1; i <= 6; i++ {
        if i%2 == 0 {
            continue
        }
        fmt.Println(i)
    }
}
```

Output:
```
1
3
5
```

**`continue`** melompati **sisa kode di iterasi saat ini** dan langsung lanjut ke iterasi berikutnya (klausa post tetap dijalankan). Di sini, setiap `i` genap dilompati — `fmt.Println(i)` tidak pernah tercapai untuk angka genap, jadi hanya angka ganjil yang tercetak.

:::tip
Bedanya `break` dan `continue`: `break` = "berhenti total", `continue` = "lewati yang ini, lanjut ke berikutnya". Kalau kamu bingung membedakan, bayangkan `break` seperti keluar dari ruangan, `continue` seperti melewati satu meja untuk lanjut ke meja berikutnya di ruangan yang sama.
:::

## Label untuk Loop Bersarang

Ini fitur khas Go yang jarang ada di bahasa lain: `break`/`continue` biasa hanya mempengaruhi loop **terdalam** tempat ia ditulis. Kalau kamu punya loop di dalam loop dan ingin `break` sampai ke loop **terluar**, kamu butuh **label**.

```go
package main

import "fmt"

func main() {
cariAngka:
    for i := 1; i <= 3; i++ {
        for j := 1; j <= 3; j++ {
            if i*j == 6 {
                fmt.Println("Ditemukan:", i, "x", j, "= 6")
                break cariAngka
            }
            fmt.Println("Coba:", i, "x", j)
        }
    }
    fmt.Println("Pencarian selesai")
}
```

Output:
```
Coba: 1 x 1
Coba: 1 x 2
Coba: 1 x 3
Coba: 2 x 1
Coba: 2 x 2
Ditemukan: 2 x 3 = 6
Pencarian selesai
```

## Membedah Label

**`cariAngka:`** — label, ditulis tepat sebelum keyword `for` yang ingin ditandai. Namanya bebas, konvensinya camelCase seperti nama variabel.

**`break cariAngka`** — menghentikan **loop yang punya label itu**, bukan cuma loop terdalam. Tanpa label, `break` di sini hanya akan menghentikan loop `j` bagian dalam, lalu loop `i` bagian luar tetap lanjut berjalan — bukan itu yang kita mau.

:::note
`continue label` juga valid — melompat ke iterasi berikutnya dari loop yang punya label tersebut, bukan cuma loop terdalam. Pola ini jarang dipakai untuk kasus sederhana, tapi sangat berguna saat kamu butuh mencari sesuatu di dalam struktur data bersarang (matriks, grid, dsb).
:::

## Kesalahan Umum

1. **Mengira break biasa keluar dari SEMUA loop bersarang:**
   ```go
   for i := 1; i <= 3; i++ {
       for j := 1; j <= 3; j++ {
           if i*j == 6 {
               break  // cuma keluar loop j, loop i tetap lanjut!
           }
       }
   }
   ```
   Kalau maksudnya keluar dari kedua loop sekaligus, kamu butuh label — `break` tanpa label hanya mempengaruhi loop terdekat.

2. **Lupa continue tetap menjalankan klausa post:**
   ```go
   for i := 0; i < 5; i++ {
       if i == 2 {
           continue  // i++ tetap jalan, loop tidak macet
       }
       fmt.Println(i)
   }
   ```
   `continue` tidak melompati klausa post (`i++`) — kalau kamu lupa ini dan mengira perlu increment manual sebelum `continue`, kamu bisa tidak sengaja melompati dua nilai sekaligus.

## Ringkasan

| Konsep | Efek |
|---|---|
| `break` | Hentikan loop terdekat sepenuhnya |
| `continue` | Lompati sisa iterasi, lanjut ke berikutnya |
| `label:` | Beri nama pada loop |
| `break label` / `continue label` | Kontrol loop luar dari dalam loop bersarang |

Di pelajaran berikutnya, kita akan bahas **nested loops** lebih dalam — loop di dalam loop untuk membuat pola dan tabel!
