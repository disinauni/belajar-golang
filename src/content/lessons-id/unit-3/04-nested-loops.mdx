# Nested Loops

Kamu sudah melihat sekilas loop bersarang di pelajaran Label. Sekarang mari kuasai pola ini secara formal — ini fondasi penting untuk project unit ini: membuat pola bintang.

## Loop di Dalam Loop

```go
package main

import "fmt"

func main() {
    for baris := 1; baris <= 3; baris++ {
        for kolom := 1; kolom <= 3; kolom++ {
            fmt.Printf("(%d,%d) ", baris, kolom)
        }
        fmt.Println()
    }
}
```

Output:
```
(1,1) (1,2) (1,3) 
(2,1) (2,2) (2,3) 
(3,1) (3,2) (3,3) 
```

## Membedah Loop Bersarang

**Loop luar (`baris`)** berjalan 3 kali. **Untuk setiap satu iterasi loop luar**, loop dalam (`kolom`) berjalan **penuh** dari awal sampai akhir (3 kali juga) — jadi totalnya loop dalam dieksekusi `3 × 3 = 9` kali.

**`fmt.Println()`** di luar loop dalam (tapi masih di dalam loop luar) — dipanggil sekali setiap `baris` selesai, untuk pindah ke baris baru di output.

Bayangkan ini seperti jam dinding: setiap satu putaran jarum jam (loop luar), jarum detik (loop dalam) sudah berputar penuh 60 kali.

:::tip
Aturan sederhana untuk menghitung total iterasi nested loop: kalikan jumlah iterasi tiap level. Loop luar 3x, loop dalam 3x → total `3 × 3 = 9` eksekusi bagian terdalam. Kalau ada 3 level loop masing-masing 10x, totalnya `10 × 10 × 10 = 1000`!
:::

## Membuat Pola Sederhana

```go
package main

import "fmt"

func main() {
    for baris := 1; baris <= 5; baris++ {
        for kolom := 1; kolom <= baris; kolom++ {
            fmt.Print("*")
        }
        fmt.Println()
    }
}
```

Output:
```
*
**
***
****
*****
```

Perhatikan `kolom <= baris` — bukan angka tetap! Jumlah bintang per baris **ikut berubah** sesuai nilai `baris` saat ini. Ini pola yang sangat umum untuk membuat segitiga, dan jadi dasar project pola bintang di pelajaran berikutnya.

:::note
Trik nested loop untuk pola: loop luar biasanya mengontrol **berapa baris**, loop dalam mengontrol **apa yang dicetak di satu baris itu**. Kondisi loop dalam sering bergantung pada variabel loop luar, seperti contoh `kolom <= baris` di atas.
:::

## Kesalahan Umum

1. **Salah urutan variabel, bikin pola terbalik dari yang diharapkan:**
   ```go
   for baris := 1; baris <= 5; baris++ {
       for kolom := 1; kolom <= 6-baris; kolom++ {  // bukan <= baris
           fmt.Print("*")
       }
       fmt.Println()
   }
   // Menghasilkan segitiga terbalik, bukan segitiga normal
   ```
   Selalu cek dengan hati-hati kondisi loop dalam — salah tanda `<=` vs `>=`, atau salah variabel, bisa membalik seluruh pola.

2. **Lupa `fmt.Println()` untuk pindah baris:**
   ```go
   for baris := 1; baris <= 3; baris++ {
       for kolom := 1; kolom <= 3; kolom++ {
           fmt.Print("*")
       }
       // lupa fmt.Println() di sini!
   }
   // Output: *********  (semua nempel jadi satu baris)
   ```
