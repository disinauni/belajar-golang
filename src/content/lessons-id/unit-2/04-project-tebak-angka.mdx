# Project: Game Tebak Angka

Saatnya menerapkan semua yang kamu pelajari di Unit 2 — operator perbandingan, operator logika, if-else, dan switch — untuk membuat game sederhana: **Tebak Angka**.

## Spesifikasi Program

Game kita harus bisa:

1. Menghasilkan angka rahasia acak antara 1-100
2. Meminta user menebak berulang kali (maksimal 7 percobaan)
3. Memberi petunjuk "terlalu tinggi" atau "terlalu rendah" setiap tebakan salah
4. Mengumumkan menang/kalah di akhir

Contoh interaksi yang diharapkan:
```
=== TEBAK ANGKA (1-100) ===
Kamu punya 7 kesempatan.

Tebakan ke-1: 50
Terlalu tinggi!

Tebakan ke-2: 25
Terlalu rendah!

Tebakan ke-3: 37
Tepat! Kamu menang dalam 3 percobaan.
```

## Tahap 1: Planning

**Data apa yang perlu disimpan?**
- Angka rahasia (`int`, hasil random 1-100)
- Tebakan user di setiap percobaan (`int`)
- Jumlah percobaan yang sudah dipakai (`int`)
- Status menang/kalah (`bool`)

**Alur program:**
1. Generate angka rahasia acak
2. Loop maksimal 7 kali:
   - Minta tebakan user
   - Bandingkan dengan angka rahasia
   - Kalau tepat: menang, keluar dari loop
   - Kalau salah: beri petunjuk tinggi/rendah
3. Kalau 7 percobaan habis tanpa menang: kalah, tampilkan angka yang benar

**Edge case yang perlu dipikirkan:**
- Bagaimana kalau user menebak tepat di percobaan terakhir?
- Bagaimana kalau user menebak angka yang sama berulang kali?

## Tahap 2: Pseudocode

```
PROGRAM TebakAngka:
    angkaRahasia = random(1, 100)
    maksPercobaan = 7

    UNTUK percobaan DARI 1 SAMPAI maksPercobaan:
        MINTA tebakan dari user
        JIKA tebakan == angkaRahasia:
            TAMPILKAN "Tepat! Menang dalam " + percobaan + " percobaan"
            KELUAR dari program
        JIKA tebakan > angkaRahasia:
            TAMPILKAN "Terlalu tinggi!"
        SELAIN ITU:
            TAMPILKAN "Terlalu rendah!"

    TAMPILKAN "Kalah! Angka yang benar: " + angkaRahasia
```

## Tahap 3: Implementasi

Karena `for` loop baru dibahas formal di Unit 3, versi pertama ini kita buat sederhana dulu — cukup satu kali tebak, sebelum nanti dibungkus loop di Challenge Bonus.

### Versi 1: Satu Kali Tebak

```go
package main

import (
    "bufio"
    "fmt"
    "math/rand"
    "os"
    "strconv"
    "time"
)

func main() {
    rand.Seed(time.Now().UnixNano())
    angkaRahasia := rand.Intn(100) + 1 // 1-100

    scanner := bufio.NewScanner(os.Stdin)

    fmt.Println("=== TEBAK ANGKA (1-100) ===")
    fmt.Print("Tebakanmu: ")
    scanner.Scan()
    tebakan, _ := strconv.Atoi(scanner.Text())

    if tebakan == angkaRahasia {
        fmt.Println("Tepat!")
    } else if tebakan > angkaRahasia {
        fmt.Println("Terlalu tinggi!")
    } else {
        fmt.Println("Terlalu rendah!")
    }
}
```

Coba jalankan beberapa kali — perhatikan angka rahasianya berubah tiap kali program dijalankan.

### Versi 2: Batasi Percobaan dengan Switch untuk Status

Sekarang tambahkan pelacakan percobaan dan pengumuman hasil akhir, memakai `switch` untuk merapikan pesan status:

```go
package main

import (
    "bufio"
    "fmt"
    "math/rand"
    "os"
    "strconv"
    "time"
)

func main() {
    rand.Seed(time.Now().UnixNano())
    angkaRahasia := rand.Intn(100) + 1

    scanner := bufio.NewScanner(os.Stdin)
    percobaan := 1
    menang := false

    fmt.Println("=== TEBAK ANGKA (1-100) ===")
    fmt.Println("Kamu punya 3 kesempatan (versi demo).")
    fmt.Println()

    fmt.Printf("Tebakan ke-%d: ", percobaan)
    scanner.Scan()
    tebakan, _ := strconv.Atoi(scanner.Text())

    switch {
    case tebakan == angkaRahasia:
        menang = true
    case tebakan > angkaRahasia:
        fmt.Println("Terlalu tinggi!")
    default:
        fmt.Println("Terlalu rendah!")
    }

    if menang {
        fmt.Printf("\nTepat! Kamu menang dalam %d percobaan.\n", percobaan)
    } else {
        fmt.Printf("\nBelum tepat. Angka rahasianya %d.\n", angkaRahasia)
    }
}
```

Ini adalah versi dasarnya! Mari kita pahami bagian-bagian pentingnya.

## Memahami Kode

### Angka Acak dengan math/rand

```go
rand.Seed(time.Now().UnixNano())
angkaRahasia := rand.Intn(100) + 1
```

`rand.Seed(...)` memberi "titik awal" acak berdasarkan waktu saat ini — tanpa ini, program akan menghasilkan urutan angka "acak" yang **sama persis** setiap kali dijalankan (karena Go 1.13.5 tidak auto-seed seperti versi lebih baru). `rand.Intn(100)` menghasilkan angka acak dari `0` sampai `99`, jadi kita tambah `1` supaya rentangnya jadi `1` sampai `100`.

### Variabel `menang` sebagai Flag

```go
menang := false
// ...
switch {
case tebakan == angkaRahasia:
    menang = true
// ...
}

if menang {
    // ...
}
```

Sama seperti kalkulator di Unit 1, kita pakai variabel `bool` sebagai "bendera" untuk menandai kondisi tertentu terjadi di dalam blok yang lebih dalam, lalu dicek lagi di luar.

:::

## Challenge Bonus

Sudah paham dasarnya? Coba tantangan ini untuk melengkapi game-nya:

**Challenge 1: Bungkus dengan Loop**

Ini tantangan utama! Kita belum belajar `for` secara formal (itu Unit 3), tapi kalau kamu penasaran, coba bungkus proses tebak dengan `for percobaan := 1; percobaan <= 7; percobaan++ { ... }` supaya user bisa menebak sampai 7 kali atau sampai menang — gunakan `break` untuk keluar loop begitu menang.

**Challenge 2: Validasi Input**

Tambahkan pengecekan: kalau `strconv.Atoi` gagal (user mengetik bukan angka), tampilkan pesan error dan minta input ulang, tanpa menghitungnya sebagai percobaan.

**Challenge 3: Rentang yang Bisa Disesuaikan**

Ubah program supaya rentang angka rahasia (`1-100`) bisa disesuaikan lewat variabel di awal program, misalnya `1-50` untuk mode mudah atau `1-500` untuk mode sulit.
