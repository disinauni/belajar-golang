# Parameter & Return

Fungsi `sapa()` di pelajaran sebelumnya selalu mencetak pesan yang sama persis — tidak fleksibel. Fungsi jadi jauh lebih berguna ketika bisa **menerima data** (parameter) dan **mengembalikan hasil** (return value). Mari kita buat fungsi yang benar-benar "bekerja" dengan data yang kamu berikan.

## Fungsi dengan Parameter dan Return

```go
package main

import "fmt"

func tambah(a int, b int) int {
    hasil := a + b
    return hasil
}

func main() {
    total := tambah(3, 4)
    fmt.Println(total)
    fmt.Println(tambah(10, 20))
}
```

Output:
```
7
30
```

## Membedah Parameter dan Return

**`func tambah(a int, b int) int`** — mari pecah:
- `a int, b int` — daftar **parameter**: variabel yang menerima nilai dari pemanggil, masing-masing dengan tipe eksplisit. Berbeda dari Python atau JavaScript, di Go **setiap parameter wajib punya tipe** — tidak ada parameter "tanpa tipe"
- `int` (setelah tanda kurung) — **tipe return value**: tipe data yang akan dikembalikan fungsi ini

**`return hasil`** — mengembalikan nilai `hasil` ke pemanggil, sekaligus **langsung menghentikan** eksekusi fungsi di titik itu juga. Kode setelah `return` dalam fungsi yang sama tidak akan pernah dijalankan.

**`tambah(3, 4)`** — memanggil fungsi dengan **argumen** `3` dan `4`. Argumen ini disalin ke parameter `a` dan `b` di dalam fungsi. Nilai yang dikembalikan (`7`) bisa langsung dipakai — disimpan ke variabel (`total := tambah(3, 4)`) atau dipakai langsung (`fmt.Println(tambah(10, 20))`).

Bayangkan fungsi seperti mesin vending: kamu masukkan uang (argumen), mesin memprosesnya (body fungsi), dan kamu menerima barang (return value) di ujungnya.

### Penulisan Ringkas untuk Parameter Bertipe Sama

Kalau beberapa parameter berurutan punya tipe yang sama, kamu bisa menuliskan tipenya sekali saja di akhir:

```go
func tambah(a, b int) int {
    return a + b
}
```

Ini setara persis dengan `func tambah(a int, b int) int` — cuma lebih ringkas. Aturannya: tipe cukup ditulis setelah parameter **terakhir** dalam grup yang bertipe sama.

:::note
**Parameter dilewatkan by value (disalin)** — ketika kamu memanggil `tambah(3, 4)`, nilai `3` dan `4` **disalin** ke dalam parameter `a` dan `b`. Mengubah `a` di dalam fungsi **tidak** memengaruhi variabel asli di pemanggil. Ini beda dengan beberapa bahasa lain yang melewatkan objek by reference secara default.
:::

:::tip
Kalau grup parameter tipenya campuran, kamu bisa gabungkan gaya ringkas dan eksplisit: `func buatProfil(nama string, umur, tinggi int)` — `umur` dan `tinggi` sama-sama `int` jadi cukup ditulis sekali, tapi `nama` beda tipe jadi tetap perlu ditulis eksplisit.
:::

## Contoh: Parameter Campuran

```go
package main

import "fmt"

func perkenalan(nama string, umur int) string {
    return nama + " berumur " + fmt.Sprint(umur) + " tahun"
}

func main() {
    fmt.Println(perkenalan("Rani", 20))
}
```

Output:
```
Rani berumur 20 tahun
```

Perhatikan `fmt.Sprint(umur)` — dipakai untuk mengonversi `int` menjadi `string` supaya bisa digabung dengan `+`. Go tidak mengizinkan menggabung `string` dan `int` langsung dengan `+` (beda tipe, harus dikonversi dulu — sama seperti prinsip konversi tipe yang sudah kamu pelajari di Unit 1).

## Kesalahan Umum

1. **Lupa menulis tipe return, tapi tetap ada statement `return`:**
   ```go
   func tambah(a, b int) { // ERROR: tidak ada tipe return dideklarasikan
       return a + b        // ERROR: too many return values
   }
   ```
   Kalau fungsi mengembalikan nilai, tipe return **wajib** dideklarasikan setelah daftar parameter.

2. **Fungsi dengan tipe return tapi lupa `return` di beberapa alur:**
   ```go
   func absolut(n int) int {
       if n < 0 {
           return -n
       }
       // ERROR: missing return at end of function
   }
   ```
   Go **memaksa** setiap alur eksekusi yang mungkin harus diakhiri dengan `return` kalau fungsinya punya tipe return — compiler akan menolak kalau ada jalur yang "lolos" tanpa return.

3. **Mengira parameter diubah di dalam fungsi akan memengaruhi variabel asli:**
   ```go
   func gandakan(n int) {
       n = n * 2
   }

   func main() {
       angka := 5
       gandakan(angka)
       fmt.Println(angka) // tetap 5, bukan 10 — karena n cuma salinan
   }
   ```

## Ringkasan

| Konsep | Contoh |
|---|---|
| Parameter eksplisit | `func f(a int, b int)` |
| Parameter ringkas (tipe sama) | `func f(a, b int)` |
| Tipe return | `func f(a, b int) int` |
| Mengembalikan nilai | `return hasil` |
| Parameter = salinan (by value) | Mengubah parameter tidak memengaruhi variabel asli |

Sejauh ini fungsi kita cuma bisa mengembalikan **satu** nilai. Di pelajaran berikutnya kita akan belajar salah satu fitur paling khas Go: **multiple return values** — mengembalikan lebih dari satu nilai sekaligus dari satu fungsi.
